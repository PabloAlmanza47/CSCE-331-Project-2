# Group Style Guide

## Character Spacing
- Put a space before and after operation symbols (1 + 1)
- Put a space after commas (between parameters/arguments)

## Blank Lines
- Use blank lines to separate functions and blocks of code
- Use one blank line of space

## Indentation
- 4-space indentation (tab)

## Variable Declarations
- Use one space before and after the equals sign
- Use camelCase for variable names
- Group similar variable types together in class variable declarations

## Case Statements
- Use camelCase

## Comments
- Leave one empty line between a comment and the code it describes, on both sides

## Curly Braces
- Opening brace goes inline on the same line as the statement
- Closing brace goes on its own line

## General Formatting Example
```
if (condition){
    //code
}
```
